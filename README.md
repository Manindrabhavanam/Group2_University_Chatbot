# AI-Powered University Student Support Chatbot

This project is developed as part of the Human-Computer Interaction course project.

The chatbot is designed to answer university-related questions using Artificial Intelligence and Natural Language Processing techniques. The system uses Hugging Face Transformers and Gradio to create a conversational chatbot interface.

## Features

* AI-powered chatbot responses
* Gradio-based web interface
* Hugging Face model integration
* Local execution on standard laptops
* QA testing and response validation

## Technologies Used

* Python
* Hugging Face Transformers
* Gradio
* Torch
* Sentence Transformers
* FAISS

## Project Structure

* `app.py` → Main chatbot application
* `requirements.txt` → Required Python libraries
* `test_cases.txt` → QA testing documentation
* `screenshots/` → Chatbot interface screenshots

Install dependencies:

pip install -r requirements.txt

Run the chatbot:

python app.py

The chatbot will run locally using Gradio.
